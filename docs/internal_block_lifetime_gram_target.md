# Internal Gram proof target

For a finite terminal block and canonical lifetime universe, the remaining arithmetic task is to estimate the general-lag correlations of the internal atom vectors.

A sufficient route is:

1. prove fixed-lag cancellation for each lag;
2. prove a uniform summable envelope in the lag variable;
3. sum the lag decomposition of the coherent internal Gram energy.

Lag one or lag two alone is sufficient only if a separate theorem proves exact finite memory at that lag. The current lifetime architecture does not provide such a theorem.
