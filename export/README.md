# Public repository export

`public-repo/` is the complete copy-ready seed for `OVVO-Financial/prime-wheel-mobius`.

Copy **the contents of** `public-repo/`, not the enclosing `export/` directory, into the root of the public repository.

The package contains the current paper **Seeded Prime-Comb Dynamics and the Finite Harmonic Reduction of Primorial-Block Möbius Sums**, the standalone Lean project, the Section 7 validation program, analytic falsification gates, documentation, citation metadata, and CI workflows.

The formal theorem sources remain a curated standalone import closure. Arithmetic and Fourier proof modules reuse the checked source from the broader `RH_Lean` sandbox; the public bridge adapters and endpoint isolate the exact published theorem boundary.
