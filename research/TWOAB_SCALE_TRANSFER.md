# Numerical and exact analytic test of the 2ab scale-transfer mechanism

## Strategic question

At square-root cutoff `R`, put

```text
X = R^2 - 1.
```

Every squarefree source `m > 1` has the unique canonical pair

```text
m = c q,   q = P+(m).
```

The source enters the complete square prefix when `R > sqrt(m)` and becomes
square-root smooth when `R >= q`.  The squared-complex coordinate is

```text
m = c q,
2Y = q^2 - c^2,
Y = 2ab.
```

The question tested here is whether this common geometry genuinely scales the
lower, below-cutoff arithmetic into the upper transport arithmetic.

The answer has three layers:

1. **Yes, exactly at source level.**  The normalized `2ab` coordinate determines
   the multiplicative shift from entry to smoothness.
2. **Yes, exactly at aggregate transport level.**  The complete high-prime
   transport sum is a finite prime-dilation operator applied only to Mertens
   values below `R`.
3. **The remaining RH problem is an operator bound.**  Exact scaling does not by
   itself bound the signed output; one must control the full arithmetic
   discrepancy or exploit its cross-channel cancellation.

## 1. Exact source-resolved transfer

For source weight `w_m = mu(m)`, define the entry block and transition block

```text
e_m = floor(sqrt(m)),
h_m = q_m - 1.
```

At block `n`,

```text
entered_m(n)   = w_m 1[e_m <= n],
smooth_m(n)    = w_m 1[e_m <= n and h_m <= n],
transport_m(n) = -w_m 1[e_m <= n < h_m].
```

Therefore, source by source and after every finite summation,

```text
entered = smooth - transport.
```

The continuous dilation from entry scale to transition scale is

```text
lambda_m = q_m / sqrt(c_m q_m) = sqrt(q_m / c_m).
```

Writing

```text
z_m = (q_m^2 - c_m^2) / (2 c_m q_m),
```

one has

```text
z_m = (lambda_m^2 - lambda_m^(-2)) / 2,
log(lambda_m) = asinh(z_m) / 2.
```

Thus the normalized `2ab` location determines the exact multiplicative shift.

## 2. Square-root inversion is the common geometric map

For fixed cutoff `R`, define

```text
iota_R(x) = R^2 / x.
```

It is an involution with fixed point `R`, and

```text
iota_R(c) = q
```

when `R = sqrt(cq)`.  It maps the lower interval `[c,R]` to the upper interval
`[R,R^2/c]`.  Their Euclidean lengths obey

```text
R^2/c - R = (R/c)(R-c).
```

This proves the geometric scaling exactly.  It does **not** say that primes are
preserved by inversion; the prime density must be included in an analytic
multiplier or discrepancy.

## 3. Exact low-Mertens transform of the entire transport sum

The paper's transport term is

```text
T_R = sum_{1 <= c < R} mu(c)
        [pi(floor(X/c)) - pi(R)].
```

Every sum here is finite, so one may interchange the cofactor and prime sums:

```text
T_R
  = sum_{c<R} mu(c) sum_{R<q<=X/c, q prime} 1
  = sum_{R<q<=X, q prime} sum_{c<=X/q} mu(c).
```

Because `q > R` and `X < R^2`, one has `floor(X/q) < R`.  Hence

```text
boxed:
T_R = sum_{R<q<=X, q prime} M(floor(X/q)).
```

This is the exact analytical statement that the high transport population is
built entirely from lower-scale Mertens sums.

Grouping primes by the reciprocal coordinate `d = floor(X/q)` gives the
lower-triangular form

```text
T_R = sum_{1 <= d < R} K_R(d) M(d),
```

where

```text
K_R(d)
  = pi(floor(X/d))
    - pi(max(R, floor(X/(d+1)))).
```

The kernel is precisely the prime mass in the square-root-inverted interval

```text
X/(d+1) < q <= X/d.
```

The experiment verifies both transport formulas with zero integer error at
every sampled cutoff.

## 4. The directly mirrored part of A

Split the smooth term by orientation:

```text
A_R = A_R^+ + A_R^-,
```

where `A_R^+` consists of canonical pairs `c < q <= R`, and `A_R^-` is the
born-smooth remainder `q <= c`.

The positive-orientation part is another exact operator on lower Mertens values:

```text
A_R^+
  = -sum_{c<R} mu(c)[pi(R)-pi(c)]
  = -sum_{q<=R, q prime} M(q-1).
```

Thus both the mirrored smooth channel and the high transport channel are exact
prime transforms of Mertens values strictly below `R`.  The difficult
cancellation is not between two unrelated objects; it occurs between two
operators generated by the same canonical factor geometry.

Numerically, at `R=10000`,

```text
S_R                         =    1,928
A_R                         = -354,099
T_R                         = -356,027
A_R^+                       =    1,885
A_R^-                       = -355,984
A_R^- - T_R                 =       43.
```

So the large cancellation is specifically between the born-smooth part of `A`
and `T`, while the directly mirrored positive-orientation part already lives at
the target linear scale in this range.

## 5. Deterministic baseline scaling and the exact discrepancy

For any deterministic baseline `F`, define

```text
kappa_F(R,c)
  = [F(R^2/c)-F(R)] / [F(R)-F(c)].
```

Whenever the denominator is nonzero,

```text
F(R^2/c)-F(R) = kappa_F(R,c)[F(R)-F(c)].
```

For an observable `G`—in the experiment, the actual prime-counting function—
define

```text
E_{G,F}(R,c)
  = [G(R^2/c)-G(R)]
    - kappa_F(R,c)[G(R)-G(c)].
```

Then, identically,

```text
G(R^2/c)-G(R)
  = kappa_F(R,c)[G(R)-G(c)] + E_{G,F}(R,c).
```

After weighting by `mu(c)` and summing, transport is the scaled low-prime
operator plus one explicit signed discrepancy.  This is the exact place where a
prime-density theorem must enter.

## 8. Random-sign control

The small residual is not a generic result of interval bookkeeping.  At
`Rmax=3000`, twenty deterministic random-sign assignments on the same source
geometry gave

```text
mean energy ratio   = 0.7547
median energy ratio = 0.7545
range               = [0.1619, 1.3570].
```

The actual Mobius ratio was

```text
1.0573e-4.
```

Thus the geometry supplies the exact transfer map, but the exceptional aggregate
cancellation is arithmetic.

## 10. Remaining proof target

The scaling mechanism itself is no longer conjectural.  What remains is to prove
an RH-scale bound for the output of the exact lower-triangular operator, or for
the signed baseline discrepancy after the large deterministic scale is removed.
A sufficient target is a bound for

```text
sum_{c<R} mu(c) E_{pi,F}(R,c)
```

together with a bound for the scaled-low main term and the born-smooth remainder,
with their full signed interaction retained.

Equivalently, one may work directly with

```text
T_R = sum_{d<R} K_R(d) M(d)
```

and prove a cancellation-aware operator estimate rather than an absolute row-sum
bound.  The exact geometry has reduced the high transport problem to lower-scale
Mertens data; the unresolved step is proving that this triangular prime-dilation
operator is sufficiently contractive on the actual Mobius sequence.
