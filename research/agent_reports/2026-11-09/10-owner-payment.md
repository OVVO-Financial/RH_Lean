### D. Mathematical Derivation

#### FW1. Exact packet and ownership map

For a prime p<=y write P_(p-1)=product_(q<p) q and define

```text
B_R(p) = -sum_(e|P_(p-1)) mu(e)*fract(X/(p*e)),
Phi(t,z) = #{1<=k<=floor(t): gcd(k,P_z)=1}.
```

Every nonunit divisor has one unique factorization d=p*e with p=P+(d) and e|P_(p-1). Since mu(p*e)=-mu(e), and fract(X)=0 for the d=1 atom,

```text
F_R = sum_(p<R, p prime) B_R(p),
B_R(p) = Phi(X/p,p-1) - (X/p)*delta(p-1).       (1)
```

Proof of the second equality: expand fract(t)=t-floor(t), and apply finite divisor inclusion-exclusion to the entire e sum. For each integer k, sum_(e|P_(p-1),e|k)mu(e) is exactly 1 if gcd(k,P_(p-1))=1 and 0 otherwise. Thus multiplication by p identifies the counted k with physical n<=X whose least prime is p. Each physical n is assigned once; no historical occurrence is cloned into independent copies.

Crucially, e>X/p remains in the fractional and reciprocal sums. Its two contributions cancel individually:

```text
-mu(e)*fract(X/(pe)) + mu(e)*X/(pe) = 0,  if pe>X.
```

For pe=X the floor is one and MUST remain. The cofactor k=1 contributes the physical prime n=p; k=p contributes n=p^2. Squareful physical integers are not discarded merely because the divisor coefficients are squarefree. The prime R itself is not an owner, but can be an admitted cofactor in another owner's packet.

The finite Euler identity also yields

```text
sum_(p<R) delta(p-1)/p = 1-delta(y),
Z_R = li(X)+1-X+sum_(p<R) Phi(X/p,p-1)-pi(y).   (2)
```

Equation (2) is full bookkeeping, not a new bound. It recovers the original source with its unit correction.

If p<R and p^3>X, every counted k other than 1 must be prime: a composite k with no prime factor below p would satisfy k>=p^2>X/p. Since p^2<=X,

```text
Phi(X/p,p-1) = 1+pi(floor(X/p))-pi(p-1).         (3)
```

For R>=8 this holds for every owner R/2<=p<R; for R>=64 it holds for every owner R/4<=p<R. The strict cubic guard is essential.

There is an exact cross-owner historical triangle. For fixed alpha in (0,1), when all admitted p in [alpha R,R) satisfy the cubic guard, let n_R(alpha)=#{prime p:alpha R<=p<R}. Then

```text
sum_(alpha R<=p<R) Phi(X/p,p-1)
  = n_R(alpha)*(n_R(alpha)+3)/2 + N_cross(R,alpha),

  = #{prime pairs (p,q): alpha R<=p<R<=q, p*q<=X}.       (4)
```

#### FW3. Opposite proportional-band biases

Fix real constants 0<a<b<=1 BEFORE R and define

```text
B_R[a,b) = sum_(prime p, aR<=p<bR) B_R(p),
T_R = R^2/log^2 R.
```

Then, along the integers R tending to infinity,

```text

c(a,b) = (1-exp(-gamma))*log(b/a)-(b^2-a^2)/2.   (6)
```

The analytic inputs are ordinary, unconditional `pi(t)~t/log t` and Mertens' finite-product formula `delta(t)log t -> exp(-gamma)`. Proof with uniformity: once R>=a^(-3), p>=aR implies p^3>X. All arguments p and X/p lie in a fixed compact proportional range [aR,R/a]. PNT therefore gives UNIFORM absolute error o(R/log R) in

```text
1+pi(floor(X/p))-pi(p-1)
  = (R/log R)*(1/(p/R)-p/R)+o(R/log R).
```

There are O_(a,b)(R/log R) owners. Applying PNT partial summation to the continuous function 1/u-u on [a,b] gives

```text
sum_(aR<=p<bR) Phi(X/p,p-1)
  = (log(b/a)-(b^2-a^2)/2+o(1))*T_R.             (7)
```

The unit and prime-square counts are O(R/log R), hence lower order, but were included in the exact preceding formulas. Floors and endpoint prime admission change the asymptotic only by the controlled lower-order errors, not the exact identities.

For the Euler packet mass, uniform Mertens asymptotics on the same compact range and PNT partial summation give

```text

sum_(aR<=p<bR) 1/p = (log(b/a)+o(1))/log R,
```

This does NOT subtract two first-order Mertens equivalents to infer a second-order difference. It estimates the exact telescoping difference through its prime-adjunction increments. Combining (7)-(8) proves (6). All little-o constants and thresholds may depend on the FIXED a,b, never on a subsequently chosen scale-dependent band.

```python
"""Registered exact prime-packet checks and rational integration enclosures.

Only the six registered small cases use transcendental functions. Logarithms
are enclosed by a finite rational atanh series, never by floating-point ln.
"""

from bisect import bisect_left, bisect_right
from fractions import Fraction as Q
from functools import lru_cache
from math import isqrt, log
import json


SCALE = 10**30
LOG_TERMS = 40


def floorq(x):
    return x.numerator // x.denominator


def ceilq(x):
    return -((-x.numerator) // x.denominator)


def small_log_bounds(n, d):
    a, b = n - d, n + d
    lo = 0
    for j in range(LOG_TERMS):
        lo += (2 * pow(a, 2*j+1) * SCALE) // (pow(b, 2*j+1) * (2*j+1))
    tail = Q(2 * pow(a, 2*LOG_TERMS+1),
             pow(b, 2*LOG_TERMS+1) * (2*LOG_TERMS+1)) / (1-Q(a, b)**2)
    return lo, lo + LOG_TERMS + ceilq(tail * SCALE)


LOG_TWO = small_log_bounds(2, 1)


@lru_cache(maxsize=None)
def log_bounds(x):
    x = Q(x)
    assert x >= 1
    n, d = x.numerator, x.denominator
    k = 0
    while n >= 2*d:
        d *= 2
        k += 1
    lo, hi = small_log_bounds(n, d)
    return lo + k*LOG_TWO[0], hi + k*LOG_TWO[1]


def add(*bounds):
    return sum(x[0] for x in bounds), sum(x[1] for x in bounds)


def neg(bounds):
    return -bounds[1], -bounds[0]


def integral_density(a, b, panels):
    a, b = Q(a), Q(b)
    if b < a:
        return neg(integral_density(b, a, panels))
    if a == b:
        return 0, 0
    step = (b-a)/panels
    lo = hi = 0
    for i in range(panels):
        left, right = a+i*step, a+(i+1)*step
        lo += floorq(step*SCALE**2/log_bounds(right)[1])
        hi += ceilq(step*SCALE**2/log_bounds(left)[0])
    return lo, hi


def continuous_correction(R, W, panels):
    X = R*R-1
    total = (0, 0)
    # On each interval the width has the stated monotonicity. Bounds on
    # both density factors and on the width give rigorous rectangle sums.
    regions = [
        (Q(R-W), Q(R-1), 1, "positive"),
        (Q(R-1), Q(X, R), -1, "negative_increasing"),
        (Q(X, R), Q(R), -1, "negative_decreasing"),
    ]
    for start, end, sign, kind in regions:
        if start == end:
            continue
        step = (end-start)/panels
        lo = hi = 0
        for i in range(panels):
            left, right = start+i*step, start+(i+1)*step
            if kind == "positive":
                wlo = Q(X, right)-(2*R-right)
                whi = Q(X, left)-(2*R-left)
                vlo, vhi = 2*R-right, Q(X, left)
            elif kind == "negative_increasing":
                wlo = 2*R-left-Q(X, left)
                whi = 2*R-right-Q(X, right)
                vlo, vhi = Q(X, right), 2*R-left
            else:
                wlo, whi = R-right, R-left
                vlo, vhi = Q(R), 2*R-left
            assert 0 <= wlo <= whi
            lo += floorq(step*wlo*SCALE**3 /
                         (log_bounds(right)[1]*log_bounds(vhi)[1]))
            hi += ceilq(step*whi*SCALE**3 /
                        (log_bounds(left)[0]*log_bounds(vlo)[0]))
        total = add(total, (lo, hi) if sign == 1 else (-hi, -lo))
    return total


def primes_up_to(n):
    sieve = bytearray(b"\x01")*(n+1)
    sieve[0:2] = b"\x00\x00"
    for p in range(2, isqrt(n)+1):
        if sieve[p]:
            sieve[p*p:n+1:p] = b"\x00"*((n-p*p)//p+1)
    return [p for p in range(2, n+1) if sieve[p]]


PRIMES = primes_up_to(8192)
PSET = set(PRIMES)


def pair_case(R, W):
    X = R*R-1
    left = [p for p in PRIMES if R-W <= p < R]
    right = [q for q in PRIMES if R <= q <= 2*R]
    h = {(p, q) for p in left for q in right if p*q <= X}
    t = {(p, q) for p in left for q in right if p+q <= 2*R}
    assert t <= h
    assert all(p < q and (p*q)//p == q for p, q in h)
    assert len({p*q for p, q in h}) == len(h)
    assert all(p*q != R*R for p in left for q in right)
    eq = {(p, q) for p, q in h if p*q == X}
    expected = {(R-1, R+1)} if R-1 in left and R+1 in PSET else set()
    assert eq == expected
    short_right = [q for q in right if q <= R+W]
    rev = {(p, q) for p in left for q in short_right if p+q >= 2*R}
    diag = {(p, q) for p in left for q in short_right if p+q == 2*R}
    assert len(t)+len(rev) == len(left)*len(short_right)+len(diag)
    historical = {(p, q) for p in left for q in left if p <= q}
    assert len(left)+len(historical) == len(left)*(len(left)+3)//2
    exact_owner_total = sum(1+bisect_right(PRIMES, X//p)-bisect_left(PRIMES, p)
                            for p in left)
    assert exact_owner_total == len(left)*(len(left)+3)//2+len(h)
    return left, right, h, t, len(diag)


def outward(bounds, digits=10):
    factor = 10**digits
    a = bounds[0]*factor//SCALE
    b = -((-bounds[1]*factor)//SCALE)
    def show(n):
        return ("-" if n < 0 else "") + str(abs(n)//factor) + "." + str(abs(n)%factor).zfill(digits)
    return [show(a), show(b)]


def signed_case(R, W, panels):
    left, right, h, t, diagonal = pair_case(R, W)
    PL = add(*(integral_density(2*R-p, Q(R*R-1, p), panels) for p in left))
    LP = (0, 0)
    for q in right:
        a = max(Q(R-W), min(Q(R), Q(2*R-q)))
        b = max(Q(R-W), min(Q(R), Q(R*R-1, q)))
        LP = add(LP, integral_density(a, b, panels))
    LL = continuous_correction(R, W, panels)
    count = len(h)-len(t)
    centered = add((count*SCALE, count*SCALE), neg(PL), neg(LP), LL)
    width = Q(W*W+1, R-W)
    logw = log_bounds(Q(W+2))
    logh = log_bounds(width+2)
    bound_lower = floorq(32*W*(width+1)*SCALE**3/(logw[1]*logh[1]))
    assert max(abs(centered[0]), abs(centered[1])) <= bound_lower
    assert count*SCALE <= bound_lower
    return {
        "R": R, "W": W, "panels_per_integral": panels,
        "N_hyperbola": len(h), "N_triangle": len(t), "E_PP": count,
        "E_PL": outward(PL), "E_LP": outward(LP), "E_LL": outward(LL),
        "E_nunu": outward(centered),
        "certified_sign": -1 if centered[1] < 0 else 1 if centered[0] > 0 else 0,
        "goldbach_diagonal": diagonal,
        "pair_correction_atoms": sorted(h-t),
    }, centered


def integer_root_two_thirds(R):
    lo, hi = 0, R
    while lo+1 < hi:
        mid = (lo+hi)//2
        if mid**3 <= R*R:
            lo = mid
        else:
            hi = mid
    return lo


def main():
    checks = 0
    for R in range(8, 129):
        for W in range(1, R//2+1):
            pair_case(R, W)
            checks += 1
    large = []
    for R in (257, 1024, 4096):
        W = integer_root_two_thirds(R)
        _, _, h, t, diag = pair_case(R, W)
        large.append({"R": R, "W": W, "E_PP": len(h)-len(t),
                      "N_triangle": len(t), "diagonal": diag})
    rows = []
    for R, W in ((8, 4), (9, 4), (11, 4), (12, 5), (14, 5), (37, 11)):
        row, enclosure = signed_case(R, W, 256)
        refined, enclosure2 = signed_case(R, W, 512)
        assert enclosure[0] <= enclosure2[0] <= enclosure2[1] <= enclosure[1]
        rows.append(refined)
    # Finite constant sanity checks supplement, never replace, the proof.
    for R in range(64, 4097):
        W = integer_root_two_thirds(R)
        x = R**(1/3)
        H = (W*W+1)/(R-W)
        assert H+1 <= 2*x+1e-10
        assert H+2 >= x-1e-10
        assert W+2 >= R**(2/3)-1e-9
        assert 32*W*(H+1)/(log(W+2)*log(H+2)) <= 288*R/log(R)**2+1e-9
    print(json.dumps({
        "status": "PASS", "exact_packet_cases": checks,
        "root_range": [8, 128], "large_cases": large,
        "signed_curvature_cases": rows,
        "rounding": {"fixed_scale": str(SCALE), "atanh_terms": LOG_TERMS,
                     "quadrature": "rational monotone rectangle bounds",
                     "all_signs_certified": all(x["certified_sign"] for x in rows)},
        "constant_checks": "binary64 diagnostics only; inequalities proved separately",
        "scope": "finite evidence; no Lean or all-scale estimate inferred from tests",
    }, indent=2))


if __name__ == "__main__":
    main()
```
