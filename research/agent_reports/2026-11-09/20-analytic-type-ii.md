#### SC1. A Uniform Strip Majorant On The Actual Carrier

The only number-theory theorem used is the k=1 case of Montgomery and Vaughan, *The large sieve*, Mathematika 20 (1973), Theorem 2, equation (1.12): for every real a>0 and h>1,

```text
pi(a+h)-pi(a) < 2h/log h.
```

There are no scale-dependent implied constants or RH hypotheses. The original paper was retrieved through its [institutional repository copy, printed page 121](https://backend.production.deepblue-documents.lib.umich.edu/server/api/core/bitstreams/5adbb05b-05d0-4779-b1fd-304ec1ec257a/content); [DOI](https://doi.org/10.1112/S0025579300004708). Closed interval endpoints are handled by enlarging [a,b] to (a-1,b+1], always with positive left endpoint in this proof.

First,

```text
m(A)<=4R/L, m(B)<=4R/L.                                  (11)
```

Indeed, the prime mass of A is at most 2(R/2+2)/log(R/2+2)<=9R/(4L), since R>=8 gives log(R/2)>=2L/3. Its continuous mass is at most 3R/(4L). For B, the corresponding prime and continuous masses are at most 5R/(2L) and R/L. These prove (11) with room to spare.

For eta>=0 let

```text
U_R(eta)=integral_(A x B) 1_(|log(uv/X)|<=eta) dm(u)dm(v),
f(h)=(1+h)/log(2+h).
```

Then the following holds **for every eta>=0**, not only fixed eta:

```text
U_R(eta) <= 96 * R/L * f(R eta).                         (12)
```

For 0<=eta<=1 and fixed u in A, the allowed v form an interval in B of length at most

```text
(X/u)*(exp(eta)-exp(-eta)) <= 6R eta.
```

Here X/u<2R, and exp(eta)-exp(-eta)<=3eta on [0,1]. Set h=R eta. Enlarging that interval by one at each end and applying the displayed sieve theorem bounds its prime mass by

```text
2(6h+2)/log(6h+2) <= 12(h+1)/log(h+2).
```

Its continuous mass is at most 6h/L. Integrating over A and using (11) gives

```text
U_R(eta) <= 48 R/L*f(h)+24Rh/L^2 <= 96 R/L*f(h),
```

because h<=R and log(h+2)<=2L. If eta>=1, use U_R(eta)<=16R^2/L^2 from (11), monotonicity of f, and f(R)>=R/(2L). This also implies (12). Monotonicity follows directly from
log(h+2)>(h+1)/(h+2), h>=0.

This argument treats prime-prime, prime-continuous, continuous-prime and continuous-continuous masses together, with no independent-density assumption. Every bound remains uniform as eta changes with R.

#### SC3. Exact Finite-Frequency Expression, Including The Constant Mode

Define the even cubic spline

```text
b(w)=1-6w^2+6|w|^3                 if |w|<=1/2,
     2(1-|w|)^3                   if 1/2<=|w|<=1,
     0                            if |w|>=1.
```

It is nonnegative and b(0)=1. An elementary Fourier verification is as follows. For g(v)=max(1-|v|,0), direct piecewise integration gives b(w)=(3/2)*(g*g)(2w). Also integral g(v)exp(i z v)dv=sinc(z/2)^2. Hence, with angular Fourier convention,

```text
(1/(2*pi))*integral_(-T,T) b(t/T)exp(i t s)dt = K_T(s).
```

The continuous compactly supported spline and its integrable inverse transform obey Fourier inversion. In particular integral K_T=b(0)=1. Integrating the cosine form from 0 to s proves

```text
W_T(s)=1/2+(1/pi)*integral_0^T b(t/T)*sin(ts)/t dt.        (15)
```

For real t set

```text
A_R(t)=integral_A (u/R)^(-it) dnu(u),
B_R(t)=integral_B (v/R)^(-it) dnu(v),
a_R=log(X/R^2).
```

Then, exactly,

```text
Qerr_(R,T) = A_R(0) B_R(0)/2
 + (1/pi)*integral_0^T b(t/T)
       *Im(exp(i t a_R)*A_R(t)*B_R(t))/t dt.             (16)
```

The two factors are NOT complex conjugated; that would replace a product boundary by a ratio boundary. Fubini is legitimate: the measures have finite total variation, logarithms stay bounded on A x B, and sin(ts)/t has a bounded limit as t tends to zero. The imaginary numerator in (16) is O(t) at zero. Do not split it into separately divergent complex 1/t integrals.

In particular,

```text
A_R(0)=pi(R^-)-pi((R/2)^-)-[li(R)-li(R/2)],
B_R(0)=pi(2R)-pi(R^-)-[li(2R)-li(R)].
```

Neither is identically zero. Equation (16) is a representation, not an estimate for its signed integral.

    return n >= 2 and all(n % d for d in range(2, isqrt(n) + 1))


def triangle(x):
    return max(Q(0), 1 - abs(x))

    w = abs(w)

    if w <= 1:

    return Q(0)


def triangle_convolution(w):
    shift = 2 * w
    points = sorted({Q(-1), Q(0), Q(1), shift - 1, shift, shift + 1})
    integral = Q(0)

        f = lambda x: triangle(x) * triangle(x - shift)
        integral += (b - a) * (f(a) + 4 * f((a + b) / 2) + f(b)) / 6
    return Q(3, 2) * integral

"""Registered diagnostics for analytic-2/MB, not interval or Lean proofs."""

import json
import math

import numpy as np
from numpy.polynomial.legendre import leggauss


ROOTS = (8, 11, 12, 64, 256, 1024, 4096)
MODEL_ROOTS = (4096, 16384, 65536, 1000000)
ELL = math.log(2)


def primes_through(n):
    sieve = bytearray(b"\x01") * (n + 1)
    sieve[:2] = b"\x00\x00"
    for p in range(2, math.isqrt(n) + 1):
        if sieve[p]:
            sieve[p * p:n + 1:p] = b"\x00" * ((n - p * p) // p + 1)
    answer = [p for p in range(n + 1) if sieve[p]]
    trial = [p for p in range(2, n + 1)
             if all(p % d for d in range(2, math.isqrt(p) + 1))]
    assert answer == trial
    return answer


def grid(a, b, order, max_width=None):
    count = 1 if max_width is None else max(1, math.ceil((b - a) / max_width))
    nodes, weights = leggauss(order)
    walls = np.linspace(a, b, count + 1)
    half = (walls[1:] - walls[:-1]) / 2
    mid = (walls[1:] + walls[:-1]) / 2
    return ((mid[:, None] + half[:, None] * nodes).ravel(),
            (half[:, None] * weights).ravel())


def spline(w):
    w = np.abs(np.asarray(w))
    return np.where(w <= 0.5, 1 - 6 * w**2 + 6 * w**3,
                    np.where(w < 1, 2 * (1 - w)**3, 0))


def band_grid(root, U, order):
    # Respect the known spline join instead of integrating across its kink.
    walls = sorted({U, 2 * U} | ({root / 2} if U < root / 2 < 2 * U else set()))
    parts = [grid(a, b, order, max_width=4) for a, b in zip(walls, walls[1:])]
    return np.concatenate([p[0] for p in parts]), np.concatenate([p[1] for p in parts])


def prime_transform(root, primes, t):
    logs = np.log(np.asarray(primes, dtype=float) / root)
    return np.array([np.exp(-1j * v * logs).sum() for v in t])


def continuous_transform(root, lo, hi, t, order):
    # Composite oscillatory quadrature limits each log-panel's phase span.
    s, ws = grid(math.log(lo / root), math.log(hi / root), order,
                 max_width=12 / max(1, float(max(t))))
    density = root * np.exp(s) / (math.log(root) + s)
    result = np.empty(len(t), dtype=complex)
    for start in range(0, len(t), 16):
        tt = t[start:start + 16]
        result[start:start + 16] = (
            np.exp(-1j * tt[:, None] * s[None, :]) @ (ws * density))
    return result


def actual_case(root, U, left, right, s_order, t_order):
    t, wt = band_grid(root, U, t_order)
    pm = prime_transform(root, left, t)
    pp = prime_transform(root, right, t)
    cm = continuous_transform(root, root / 2, root, t, s_order)
    cp = continuous_transform(root, root, 2 * root, t, s_order)
    aa, bb = pm - cm, pp - cp
    phase = np.exp(1j * t * math.log1p(-1 / root**2))
    results = []
    for eta in (np.ones(len(t)), spline(t / root)):
        def band(z):
            return float(np.dot(wt, eta * (phase * z).imag / (math.pi * t)))
        terms = [band(pm * pp), band(pm * cp), band(cm * pp), band(cm * cp)]
        value = band(aa * bb)
        assert abs(value - (terms[0] - terms[1] - terms[2] + terms[3])) < 1e-8
        results.extend([value, *terms, band(aa * np.conjugate(bb))])
    results.extend([float(np.dot(wt, abs(pm)**2)),
                    float(np.dot(wt, abs(pp)**2))])
    return np.array(results)


def box_transform(w):
    w = np.asarray(w, dtype=float)
    return ELL * np.exp(-0.5j * ELL * w) * np.sinc(ELL * w / (2 * math.pi))


def model_case(root, order):
    U = math.sqrt(root)
    n = math.ceil(5 * U * ELL / (8 * math.pi))
    t0 = 2 * math.pi * n / ELL
    assert 5 * U / 4 <= t0 <= 7 * U / 4
    c = root / (4 * math.log(root))
    t, wt = grid(U, 2 * U, order, max_width=4)
    gg, hh = box_transform(t - t0), box_transform(t + t0)
    aa = c * (np.conjugate(gg) + np.conjugate(hh)) / 2
    bb = c * (gg - hh) / (2j)
    exact_imag = -(c**2 / 4) * (abs(gg)**2 - abs(hh)**2)
    assert np.max(abs((aa * bb).imag - exact_imag)) < 1e-12 * c**2
    assert np.max(exact_imag) <= 1e-10 * c**2
    weights = wt * spline(t / root) / (math.pi * t)
    raw = float(np.dot(weights, exact_imag))
    phase = np.exp(1j * t * math.log1p(-1 / root**2))
    shifted = float(np.dot(weights, (phase * aa * bb).imag))
    lower = root**1.5 / (32768 * math.log(root)**2)
    assert abs(shifted) >= lower
    phase_bound = 2 * c**2 * ELL**2 * U / (math.pi * root**2)
    assert abs(shifted - raw) <= phase_bound * (1 + 1e-9)
    assert abs(box_transform(t0)) <= 1e-12
    return np.array([raw, shifted, lower, abs(shifted) / lower, phase_bound])


all_primes = primes_through(2 * max(ROOTS))
rows_checked = 0
max_row_ratio = 0.0
max_energy_ratio = 0.0
max_reference_ratio = 0.0
max_reference_absolute_ratio = 0.0
max_band_ratio = 0.0
max_refinement = 0.0
nonconjugation_difference = 0.0
mixed_orientation_difference = 0.0
samples = []

for root in ROOTS:
    left = [p for p in all_primes if root <= 2 * p and p < root]
    right = [p for p in all_primes if root <= p <= 2 * root]
    L = math.log(root)
    assert max(len(left), len(right)) <= 4 * root / L
    assert (root in right) == (root in all_primes)
    if root == 12:
        assert 11 in left and 13 in right and 11 * 13 == root**2 - 1
    for U in (1, math.sqrt(root), root / 2, 2 * root):
        h = root / U
        f = (1 + h) / math.log(2 + h)
        for primes in (left, right):
            for p in primes:
                row = sum(math.exp(-(p - q)**2 / (16 * h**2)) for q in primes)
                max_row_ratio = max(max_row_ratio, row / (32 * f))
                assert row <= 32 * f
                rows_checked += 1
    for U in (1, math.sqrt(root), root / 2):
        base = actual_case(root, U, left, right, 96, 20)
        refined = actual_case(root, U, left, right, 144, 28)
        error = float(max(abs(base - refined)))
        max_refinement = max(max_refinement, error)
        assert error < 1e-7
        h = root / U
        f = (1 + h) / math.log(2 + h)
        energy_bound = 384 * U * root * f / L
        max_energy_ratio = max(max_energy_ratio, max(base[-2:]) / energy_bound)
        assert max(base[-2:]) <= energy_bound
        for offset in (0, 6):
            val, pp, pc, cp, cc, conjugated = base[offset:offset + 6]
            ref_ratio = abs(val - pp) / (40 * root**2 / U**2)
            absolute_ref_ratio = (abs(pc) + abs(cp) + abs(cc)) / (40 * root**2 / U**2)
            band_ratio = abs(val) / (128 * root * f / L + 40 * root**2 / U**2)
            max_reference_ratio = max(max_reference_ratio, ref_ratio)
            max_reference_absolute_ratio = max(max_reference_absolute_ratio, absolute_ref_ratio)
            max_band_ratio = max(max_band_ratio, band_ratio)
            assert ref_ratio < 1 and absolute_ref_ratio < 1 and band_ratio < 1
            nonconjugation_difference = max(nonconjugation_difference, abs(val - conjugated))
            mixed_orientation_difference = max(mixed_orientation_difference, abs(pc - cp))
        if U == math.sqrt(root):
            assert abs(base[6]) <= 384 * root**1.5 / L**2 + 40 * root
            samples.append({"R": root, "M_mid": float(base[6]),
                            "prime_prime": float(base[7]),
                            "reference_difference": float(base[6] - base[7]),
                            "new_bound": 384 * root**1.5 / L**2 + 40 * root})
    print(json.dumps({"progress_root_complete": root}), flush=True)

assert nonconjugation_difference > 1e-5
assert mixed_orientation_difference > 1e-5
model_samples = []
model_refinement = 0.0
for root in MODEL_ROOTS:

    error = float(max(abs(x - y)))

    assert error < 1e-7
    model_samples.append({"R": root, "band": float(x[1]),
                          "lower_bound": float(x[2]), "ratio": float(x[3])})

print(json.dumps({
    "status": "PASS_DIAGNOSTIC_NOT_INTERVAL_OR_LEAN_CERTIFICATE",
    "prime_bound": 2 * max(ROOTS), "prime_and_trial_count": len(all_primes),
    "actual_roots": len(ROOTS), "actual_band_cases": 3 * len(ROOTS),
    "signed_weighted_bands": 6 * len(ROOTS), "prime_rows_checked": rows_checked,

    "max_reference_bound_ratio": max_reference_ratio, "max_new_band_bound_ratio": max_band_ratio,

    "model_samples": model_samples,

### E. Mathematical Derivation

#### ZD1. Sharp Prime Transform And Every Prime Power

For either original interval I put `P_I(t)=sum_(p in I)(p/R)^(-it)` and `C_I(t)=integral_I (u/R)^(-it)du/log u`. Define the finite proper-prime-power polynomial

```text
H_I(t)=sum_(p^k in I, k>=2) (1/k)(p^k/R)^(-it).
```

The exact arithmetic identity is

```text
P_I(t)+H_I(t)=integral_I (u/R)^(-it)/log u dpsi(u).     (ZD.3)
```

This holds with the SAME half-open/closed endpoints. In particular R may be prime and belongs only to I_+; 2R is composite but can be a proper prime power and must NOT be deleted from the psi adapter. Prime squares and every higher power carry their actual 1/k coefficient.

For x=2R>=16, counting all possible bases gives

```text
sum_(p^k<=x,k>=2)1/k
 <= sqrt(x)/2+x^(1/3)*log(x)/log 2 <=4sqrt(x).
```

The last inequality follows from `log(x)<= (6/e)x^(1/6)` and `1/2+6/(e log 2)<4`. Thus `|H_I(t)|<=4sqrt(2R)` uniformly, without a prime-distribution estimate.

Choose a single T in [R^2,R^2+1] as above. On the entire interval [R/2,2R], the explicit formula's remainder E_T(x) is O(L): `x log^2(xT)/T=O(L^2/R)=O(L)`. Both one-sided values remain O(L) after any half-jump correction. This is uniform in x, including prime-power endpoints.

For `w_t(u)=(u/R)^(-it)/log u`, its endpoint sizes and derivative satisfy

```text
sup |w_t| <= 3/(2L),
integral_(R/2)^(2R)|w_t'(u)|du <= C(1+|t|)/L.
```

Stieltjes integration by parts bounds `integral_I w_t dE_T` by `C(1+|t|)`. It does not differentiate an O-term without this estimate, nor bound dE_T by its total variation. E_T is of bounded variation on the compact interval, being the difference of a finite-jump function and a finite smooth sum.

Differentiating the FINITE zero sum in the Stieltjes identity is legitimate. Its pole contribution is exactly C_I, which cancels the continuous reference. Consequently

```text
A_I(t):=P_I(t)-C_I(t)
      =-sum_(|gamma|<=T) K_I(rho,t)+r_I(t),
K_I(rho,t)=integral_I (u/R)^(-it) u^(rho-1)/log u du,
|r_I(t)|<=C(1+|t|+sqrt R)<=C sqrt R, U<=t<=2U.       (ZD.4)
```

The error includes H_I, both endpoint corrections and the explicit-formula remainder. Its normalized squared energy is O(R). This is not a claim that every mixed bilinear term with r_I separately costs O(R); the mixed terms are retained by the quadratic inequalities below.

For s=log(u/R), K_I equals `R^rho integral_J e^(beta s+i(gamma-t)s)/(L+s) ds`, where J is [-log 2,0] or [0,log 2]. The phase R^(i gamma) is retained. For g(s)=e^(beta s)/(L+s), 0<beta<1 gives `g<=3/L` and `|g'|<=2g`. Its integral is <=3/L, and integration by parts gives <=12/(L|gamma-t|). Hence

```text
|K_I(rho,t)| <=16 R^beta/[L(1+|gamma-t|)].            (ZD.5)
```

No reciprocal singularity is introduced when t=gamma, and no interval endpoint is smoothed away.

#### ZD2. Resonances, Remote Zeros And Uniformity

Let `G_R={rho: U/2<=gamma<=4U}` (positive ordinates, with multiplicities) and

```text

f(sigma)=2sigma+a(sigma)/2,

```

The symbol S_R here is a positive spectral weight, NOT Owner's physical source or any historical Mertens quantity. It is used only in this subsection and the explicitly labeled inverse statement.

By the local zero count, for U<=t<=2U,

```text

```

Weighted Cauchy-Schwarz in (ZD.5), followed by integration, therefore proves

```text
integral_U^(2U)|sum_(rho in G_R)K_I(rho,t)|^2dt
    <= C L S_R(b).                                  (ZD.6)
```

Multiplicity and every cross term are present on the left. No separation of simple zeros or random phases is assumed.

Layer-cake summation in beta, using the density theorem, gives

```text

       <= C R^f(b) L^5.                             (ZD.7)
```

Zeros below 1/2 are covered by the first term, not identified individually with reflected zeros. To justify the last integral uniformly, observe

```text

```

This works also at b=1/2, when the integral is empty. The count at 4U costs only an absolute constant because 0<=a(sigma)<=1.

It remains essential to pay every other zero, not simply cut the explicit formula at the moving resonance height. Zeros with |gamma|<=4U outside G_R are at distance at least U/2 from [U,2U]. Zeros with |gamma|>4U have distance at least |gamma|/2. For any V>=2,

```text

 <= C R^(1/2)V log(2V)
       +C L integral_(1/2)^b R^sigma V^a(sigma)(log(2V))^5 dsigma.
```

Apply this once at V=4U and then on dyadic heights V from 4U through T. There are O(L) such heights, and log(2V)=O(L) because T<=R^2+1. For V>=4U and sigma>=1/2, `a(sigma)<=1`, so

```text

```

Together with the factor 1/L in (ZD.5), this proves the uniform pointwise bound

```text
|sum_(|gamma|<=T, rho not in G_R)K_I(rho,t)|
    <= C R^g_b L^6, U<=t<=2U.                       (ZD.8)
```

The small-real-part term is O(R^(1/2)L), which is included because g_b>=g(1/2)=1/2. Negative ordinates, small positive ordinates and the entire high truncation tail have now been accounted for. Only finite sums were rearranged; this is NOT an assertion of absolute convergence of the infinite zero expansion.

```text

         <=2sigma+a(sigma)/2-1/2

```

The first inequality uses a<=1; the second uses the proved monotonicity. For the coarse b=7/8 one can additionally calculate `g_b=3-sqrt(6)`, attained at sigma=2-sqrt(6)/2. This sharpens the displayed remote budget but is not needed for (ZD.1).
