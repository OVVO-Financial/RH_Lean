
Indeed sum_(d<=t)mu(d)log(H/d)floor(t/d)=log H+psi(t), and subtracting the terms d<=H proves the equality. It is valid even when floor t<=H; then the left side is zero. Integer discontinuities have measure zero.

Multiply by w_N and integrate. The constant vanishes and integral t*w_N(t)dt=1. Stieltjes integration by parts, with compact zero boundary values, yields

```text
integral w_N(t)*psi(t)dt=N^(-1)*sum Lambda(n)*g(n/N)=1+P(N).
```

Thus the SIGNED exact identity is


There is no separate base/correction norm in this formula. The fixed target constant 1, the genuine prime powers, and the reciprocal-Mobius term are all present. Equivalently, the periodic integral can be evaluated by the finite exact quadrature

The k=1 term is retained: although integer residues for k=1 vanish, its continuous fractional part is part of the exact t-coordinate identity.

#### E4. The Contracting-Pole Argument

For Re(s)>0, absolute convergence alone gives

```text
integral_1^infinity V(x)*x^(-s-1)dx
     =1/s - 1/[s^2*zeta(1+s)].
```

Define ghat(z)=integral g(v)*v^(z-1)dv, an entire function because g has compact support away from zero. Substituting x=y^(4/5) in the prime term gives, again with absolutely convergent sums,

```text
integral_1^infinity P(x^(5/4))*x^(-s-1)dx
 = -(4/5)*ghat(1+4s/5)*zeta'(1+4s/5)/zeta(1+4s/5)-1/s.
```

There is no lower-limit correction: g is supported below 1, and n>=1 makes the substitution integral contain its whole support. The two 1/s terms cancel. Hence

```text
F(s)=-1/[s^2*zeta(1+s)]
     -(4/5)*ghat(1+4s/5)*zeta'(1+4s/5)/zeta(1+4s/5).        (M)
```

Both sides have meromorphic continuation to Re(s)>-a, and the left side is holomorphic there by (W). The apparent singularity at s=0 is removable; this also follows from ghat(1)=1 and the residue-one zeta pole.

Suppose an actual zero rho has Re(rho)>1-a. At s=rho-1, the first term of (M) has a nonremovable pole. Since s!=0, its coefficient cannot vanish. The second term can have a pole there only if

```text

```

is also a zeta zero. If ghat happens to vanish, it can remove that second pole, not rescue cancellation; the necessity of a zero remains. Multiple zeros cause no loophole: the logarithmic derivative has only a simple pole, making cancellation of a higher-order first pole impossible.

Apply the same argument at rho_1, then repeatedly. Every rho_j=1+(4/5)^j*(rho-1) has real part >1-a, is distinct from 1, and would be a zeta zero. But rho_j tends to 1, whereas (z-1)zeta(z) is holomorphic and equals 1 at z=1. There is a punctured zero-free neighborhood of 1. Contradiction.

Thus zeta has no zero with real part >1-a=3/8+5kappa/8. This proves SP3. No quantitative lower bound for a zero's height, no assumed rightmost attained zero, and no incoming fixed zero-free strip enter the argument.

```python
from fractions import Fraction as F

def add(a, b):
    c = a.copy()
    for p, v in b.items():
        c[p] = c.get(p, F(0)) + v
        if not c[p]:
            del c[p]
    return c


def scale(a, q):
    return {p: v*q for p, v in a.items() if v*q}


def lin(terms):
    out = {}
    for a, q in terms:
        out = add(out, scale(a, q))
    return out


def factors(n):
    out = {}
    p = 2
    while p*p <= n:
        while n % p == 0:
            out[p] = out.get(p, 0) + 1
            n //= p
        p += 1
    if n > 1:
        out[n] = out.get(n, 0) + 1
    return out


def logs(n):
    return {p: F(v) for p, v in factors(n).items()}


def mu(n):
    f = factors(n)
    return 0 if any(v > 1 for v in f.values()) else (-1)**len(f)


def g(u):
    x = 3*u-F(1, 2)
    return 1890*x**4*(1-x)**4 if 0 <= x <= 1 else F(0)


def poly_mul(a, b):
    c = [F(0)]*(len(a)+len(b)-1)
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            c[i+j] += x*y
    return c


def integral01(a):
    return sum((v/F(i+1) for i, v in enumerate(a)), F(0))


def norm_constant():
    # x=3u-1/2, g=1890*x^4*(1-x)^4, w=-5670*f'(x).

    u2 = [F(1, 4), F(1), F(1)]
    b = F(5670**2, 27)*integral01(poly_mul(u2, poly_mul(fp, fp)))
    return b

    k0 = n//6
    i1, i2 = range(3*k0+1, 4*k0+1), range(5*k0+1, 6*k0+1)
    s1 = sum((F(1, k) for k in i1), F(0))
    s2 = sum((F(1, k) for k in i2), F(0))

    assert lin((corr[k], F(1, k)) for k in corr) == u
    assert lin((corr[k], F(1)) for k in corr) == v
```
