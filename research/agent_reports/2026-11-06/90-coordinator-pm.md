### D2. NS2: uniform upper bound and positive asymptotic constant

**Theorem (paper level).** For all integers H>=2,

```text
0 <= V_H <= 7H/6,
lim_(H->infinity through integers) V_H/H = C_spec > 0.
```

Here is a complete arithmetic representation and convergence proof. Let

```text
g(d) = mu(d)^2 J_2(d)/d^2,
A0 = product_p (1-p^(-2)-p^(-3)+p^(-4)),
w(q) = product_(p|q) (1+1/p-1/p^3)^(-1).
```

The empty product w(1) is 1. The product A0 converges absolutely to a positive number: each factor is positive, and its difference from 1 is O(p^-2). Then

```text
C_spec = (A0/12) sum_(j,l>=1)
  mu(j)mu(l) w(j*l) [2+|log(j/l)|] / [j*l*max(j,l)].
```

The double series is absolutely convergent. No numerical value of its sum is needed.

**Uniform upper bound.** For x=H/d>=1, monotonicity of log(x/t)/t gives

```text
|A_d| <= sum_(j<=x) log(x/j)/j <= log x + (log x)^2/2.
```

Since J_2(d)/d^2 <= 1, majorize the decreasing sum by its integral, including d=1 only for this upper bound:

```text
12 V_H <= H integral_(0,1) [log(1/u)+(log(1/u))^2/2]^2 du
        = H [2! + 3! + 4!/4] = 14H.
```

This replaces the Referee's H(1+log H)^4/4 coefficient bound by an absolute linear bound. It is a logarithmic component improvement, not an exponent improvement.

**Weighted squarefree mean.** For each fixed integer q>=1,

```text
sum_(d<=x, gcd(d,q)=1) g(d) = A0 w(q) x + o_q(x).
```

To prove this without a prime number theorem, write g=1*h in Dirichlet convolution. At every prime p,

```text
h(p)=-p^-2, h(p^2)=-(1-p^-2), h(p^r)=0 for r>=3.
```

Thus sum_n |h(n)|/n is finite, by its Euler product. Dividing sum_(n<=x)g(n)=sum_d h(d) floor(x/d) by x and using dominated convergence gives the mean sum h(d)/d=A0. For g(n) times the coprimality indicator, its local Dirichlet factor at p|q is removed. This divides the mean by 1+(1-p^-2)/p, yielding w(q). Only finitely many factors change, so absolute summability persists. The o_q term need not be uniform in q in what follows.

**Passage to the double series.** If d is not squarefree, A_d=0. Otherwise mu(dj)=mu(d)mu(j) for gcd(d,j)=1, and it vanishes when gcd(d,j)>1. Therefore, temporarily adding d=1, the square in NS1 expands as

```text
(1/12) sum_(j,l<=H) mu(j)mu(l)/(j*l)
  * sum_(d<=H/max(j,l), gcd(d,j*l)=1)
        g(d) log(H/(dj)) log(H/(dl)).
```

For fixed j,l, divide the inner sum by H. The weighted mean just proved, partial summation on [eta,1/max(j,l)], and then eta down to zero yield the limit

```text
A0 w(j*l) integral_(0,1/max(j,l)) log(1/(uj)) log(1/(ul)) du
= A0 w(j*l) [2+|log(j/l)|]/max(j,l).
```

The small-u tail is uniformly dominated by the corresponding integrable log-squared function because 0<=g(d)<=1. More explicitly, the nonnegative product of logs is decreasing on this interval, so its discrete sum/H is at most its integral from zero. This same bound controls every H, j, l. After the outside 1/(jl), its total is finite: on j<=l, summing (2+log(l/j))/(j*l^2) over j gives O((1+log l)^2/l^2), whose l-sum converges. Dominated convergence for the double sum is therefore legitimate despite the nonuniform o_q. Finally, the artificially added d=1 term is A_1^2/(12H)=O(log^4 H/H) and tends to zero. This proves existence and the displayed value of C_spec.

**Strict positivity without guessing signs of the double series.** On H/2<d<=H there is only j=1, hence

```text
V_H >= V_single(H)
    := (1/12) sum_(H/2<d<=H) g(d) log^2(H/d),
V_single(H)/H -> (A0/12) I,
I = integral_(1/2,1) log^2(1/u) du
  = 1-log 2-(log 2)^2/2 > 0.
```

The last limit is the bounded-interval weighted mean above. Consequently `(A0/12) I <= C_spec <= 7/6`. This supplies an unconditional positive lower constant for the genuine source, not a fitted finite-range assertion.

Rational prime-log polynomials certify identities. Float values below are
diagnostics only, never all-scale or certified numerical evidence.
"""

from collections import defaultdict
from fractions import Fraction as Q
from math import gcd, lcm, log
import json


def sieve(n):
    mu = [1] * (n + 1)
    mu[0] = 0
    j2 = [k * k for k in range(n + 1)]
    prime = [True] * (n + 1)
    for p in range(2, n + 1):
        if prime[p]:
            for k in range(p, n + 1, p):
                mu[k] *= -1
                j2[k] = j2[k] // (p * p) * (p * p - 1)
                if k > p:
                    prime[k] = False
            for k in range(p * p, n + 1, p * p):
                mu[k] = 0
    return mu, j2


def clean(a):
    return {k: v for k, v in a.items() if v}


def add(*terms):
    out = defaultdict(Q)
    for t in terms:
        for k, v in t.items():
            out[k] += v
    return clean(out)


def scale(a, q):
    return clean({k: v * q for k, v in a.items()})


def mul(a, b):
    out = defaultdict(Q)
    for i, v in a.items():
        for j, w in b.items():
            out[tuple(sorted(i + j))] += v * w
    return clean(out)


def logpoly(n):
    out = {}
    p = 2
    while p * p <= n:
        e = 0
        while n % p == 0:
            n //= p
            e += 1
        if e:
            out[(p,)] = Q(e)
        p += 1
    if n > 1:
        out[(n,)] = Q(1)
    return out


def weights(h, mu):
    return {k: scale(add(logpoly(h), scale(logpoly(k), -1)), mu[k])
            for k in range(1, h + 1)}

                       (Q(m % j, j) - Q(j - 1, 2 * j))
                       for m in range(period)), Q(0)) / period
