**Statement.** For ANY coefficient schedule in C29, suppose there are real A<infinity and integer K0>=1 such that

**Proof, including the discrete-to-continuous boundary.** Choose `N=6ceil(2X/3)` for positive integer X. Then `4X<=N<4X+6`, so C29c implies `Kpsi(X)=O(log(X)^2)` under boundedness. Under a hypothetical bound in C30a it instead implies `Kpsi(X)=O(X^kappa)`.

Put `D(x)=psi(2x)-2psi(x)` for real x>=1. On `[m,m+1)`, `psi(x)=psi(m)` and `psi(2x)` differs from `psi(2m)` only by the possible term `Lambda(2m+1)`. Thus

```text
|D(x)-D(m)| <= log(2m+1),
integral_m^(m+1) x^(-2) dx = 1/[m(m+1)].
```

The total error integral `integral_1^infinity log(2x+1)^2/x^2 dx` is finite. It follows that the continuous weighted energy through X is at most `2Kpsi(ceil X)+O(1)`. There is no unaccounted half-integer prime-power jump.

If `Kpsi(X)=O(X^kappa)` with kappa>=0, dyadic Cauchy-Schwarz gives, for Y>=1 and sigma>1/2,

```text
integral_Y^(2Y) |D(x)| x^(-sigma-1) dx
 <= [integral_Y^(2Y) D(x)^2/x^2 dx]^(1/2)
    [integral_Y^(2Y) x^(-2sigma) dx]^(1/2)
 = O(Y^((kappa+1)/2-sigma)).
```

Consequently the Mellin integral `F(s)=integral_1^infinity D(x)x^(-s-1)dx` converges locally uniformly and is holomorphic for `Re(s)>(kappa+1)/2`. Logarithmic derivative factors needed for holomorphy are absorbed by a fixed margin inside this half-plane. If Kpsi is O(log(X)^2), the same conclusion holds for every kappa>0, so F is holomorphic throughout `Re(s)>1/2`.

For `Re(s)>1`, direct integration of the absolutely convergent prime-power series gives

```text
F(s) = -(2^s-2) * zeta'(s)/(s*zeta(s)).                (C30b)
```

The substitution x -> 2x has NO missing initial integral: psi is zero on `[1,2)`. The factor `2^s-2` cancels the pole at s=1. At any nontrivial zero rho with `1/2<Re(rho)<1`, however, this factor is nonzero since `|2^rho|=2^Re(rho)<2`. The logarithmic derivative has a nonzero simple pole there, with residue equal to the zero's multiplicity. Division by rho does not cancel it. Meromorphic uniqueness therefore contradicts holomorphy whenever `(kappa+1)/2<Re(rho)`.

The classical facts that all nontrivial zeros lie in the open critical strip and are symmetric about 1/2 are documented in [NIST DLMF 25.10](https://dlmf.nist.gov/25.10); analytic continuation and the Euler product are in [DLMF 25.2](https://dlmf.nist.gov/25.2).     for ka, va in a.items():
        for kb, vb in b.items():
            key = tuple(sorted(ka + kb))
            out[key] = out.get(key, F(0)) + va * vb
    return {k: v for k, v in out.items() if v}


def sq(a):
    return mul(a, a)


def const(value):
    return {(): F(value)} if value else {}


def factors(n):
    out = {}
    p = 2
    while p * p <= n:
        while n % p == 0:
            out[p] = out.get(p, 0) + 1
            n //= p
        p += 1
    if n > 1:
        out[n] = 1
    return out


def logn(n):
    return {(p,): F(e) for p, e in factors(n).items()}


def mobius(n):
    f = factors(n)
    return 0 if any(e > 1 for e in f.values()) else (-1) ** len(f)


def psi(n):
    out = {}
    for p in range(2, n + 1):
        if factors(p) != {p: 1}:
            continue
        power = p
        while power <= n:
            out = add(out, {(p,): F(1)})
            power *= p
    return out


def w(m):
    return F(1, m * (m + 1))


def display(poly):
    return {"1" if not k else "*".join(f"log({p})" for p in k): str(v)
            for k, v in sorted(poly.items())}
