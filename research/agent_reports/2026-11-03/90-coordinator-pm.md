#### D5. C30: Uniform Boundedness Already Implies RH

**Statement.** For ANY coefficient schedule in C29, suppose there are real A<infinity and integer K0>=1 such that


**Proof, including the discrete-to-continuous boundary.** Choose `N=6ceil(2X/3)` for positive integer X. Then `4X<=N<4X+6`, so C29c implies `Kpsi(X)=O(log(X)^2)` under boundedness. Under a hypothetical bound in C30a it instead implies `Kpsi(X)=O(X^kappa)`.

Put `D(x)=psi(2x)-2psi(x)` for real x>=1. On `[m,m+1)`, `psi(x)=psi(m)` and `psi(2x)` differs from `psi(2m)` only by the possible term `Lambda(2m+1)`. Thus

```text
|D(x)-D(m)| <= log(2m+1),
integral_m^(m+1) x^(-2) dx = 1/[m(m+1)].
```

The total error integral `integral_1^infinity log(2x+1)^2/x^2 dx` is finite. It follows that the continuous weighted energy through X is at most `2Kpsi(ceil X)+O(1)`. There is no unaccounted half-integer prime-power jump.

If `Kpsi(X)=O(X^kappa)` with kappa>=0, dyadic Cauchy-Schwarz gives, for Y>=1 and sigma>1/2,

```text
integral_Y^(2Y) |D(x)| x^(-sigma-1) dx
 <= [integral_Y^(2Y) D(x)^2/x^2 dx]^(1/2)
    [integral_Y^(2Y) x^(-2sigma) dx]^(1/2)
 = O(Y^((kappa+1)/2-sigma)).
```

Consequently the Mellin integral `F(s)=integral_1^infinity D(x)x^(-s-1)dx` converges locally uniformly and is holomorphic for `Re(s)>(kappa+1)/2`. Logarithmic derivative factors needed for holomorphy are absorbed by a fixed margin inside this half-plane. If Kpsi is O(log(X)^2), the same conclusion holds for every kappa>0, so F is holomorphic throughout `Re(s)>1/2`.

For `Re(s)>1`, direct integration of the absolutely convergent prime-power series gives

```text
F(s) = -(2^s-2) * zeta'(s)/(s*zeta(s)).                (C30b)
```

The substitution x -> 2x has NO missing initial integral: psi is zero on `[1,2)`. The factor `2^s-2` cancels the pole at s=1. At any nontrivial zero rho with `1/2<Re(rho)<1`, however, this factor is nonzero since `|2^rho|=2^Re(rho)<2`. The logarithmic derivative has a nonzero simple pole there, with residue equal to the zero's multiplicity. Division by rho does not cancel it. Meromorphic uniqueness therefore contradicts holomorphy whenever `(kappa+1)/2<Re(rho)`.

The classical facts that all nontrivial zeros lie in the open critical strip and are symmetric about 1/2 are documented in [NIST DLMF 25.10](https://dlmf.nist.gov/25.10); analytic continuation and the Euler product are in [DLMF 25.2](https://dlmf.nist.gov/25.2). These standard inputs are used at their stated domains, not as zero-free assumptions in the critical strip. This proves the boundedness implication and C30a.

```python
                return 0
        p += 1
    return -out if n > 1 else out


def arithmetic(limit):
    mu = [1] * (limit + 1)
    mu[0] = 0
    prime = [True] * (limit + 1)
    primes = []
    for p in range(2, limit + 1):
        if prime[p]:
            primes.append(p)
            for n in range(p, limit + 1, p):
                prime[n] = False
                mu[n] *= -1
            for n in range(p * p, limit + 1, p * p):
                mu[n] = 0
    lam = [D(0)] * (limit + 1)
    for p in primes:
        power = p
        while power <= limit:
            lam[power] = D(p).ln()
            power *= p
    psi = [D(0)] * (limit + 1)
    for n in range(1, limit + 1):
        psi[n] = psi[n - 1] + lam[n]
    for n in range(1, min(limit, 400) + 1):
        assert mu[n] == mobius_trial(n)
    return mu, psi


def variance(c):
    N = len(c) - 1
    return sum((c[k] * c[j] * D(gcd(k, j) ** 2 - 1) / D(12 * k * j)
                for k in range(2, N + 1) for j in range(2, N + 1)), D(0))


def residual(c, m):
    return 1 - sum((c[k] * D(m % k) / D(k) for k in range(2, len(c))), D(0))


def energy(values, lo, hi):
    return sum((values[m] ** 2 / D(m * (m + 1)) for m in range(lo, hi + 1)), D(0))


def main():
    # These scales and rejection rules are fixed before the first run.
    Ks = (1, 2, 4, 8, 16, 32)
    exact_cases = 0
    for K in range(1, 33):
        N = 6 * K
        for b in (Fraction(-2), Fraction(-1, 3), Fraction(0), Fraction(2, 5), Fraction(1)):
            v = correction(K, b)
            assert sum(v) == 2 * b
            assert sum((v[k] / k for k in range(2, N + 1)), Fraction()) == 0
            assert sum((v[k] * Fraction(k - 1, 2 * k) for k in range(2, N + 1)), Fraction()) == b
            assert max(map(abs, v)) <= 80 * abs(b) / N
            for m in range(1, N // 2 + 1):
                assert sum((v[k] * Fraction(m % k, k) for k in range(2, N + 1)), Fraction()) == 0
            exact_cases += 1

    max_identity_error = D(0)
    rows = []
    for K in Ks:
        N = 6 * K
        T = isqrt(N ** 3)
        T += T * T < N ** 3
        limit = 4 * T
        mu, psi = arithmetic(limit)
        L = D(N).ln()
        c = [D(0)] * (N + 1)
        for k in range(2, N + 1):
            c[k] = -D(mu[k]) * (L - D(k).ln()) / L
        b = 1 - sum((c[k] * D(k - 1) / D(2 * k) for k in range(2, N + 1)), D(0))
        unit = correction(K, Fraction(1))
        v = [b * dec(q) for q in unit]
        neutral = [c[k] + v[k] for k in range(N + 1)]
        h = sum((D(k - 1) / D(2 * k) for k in range(N // 2 + 1, N + 1)), D(0))
        old = [c[k] + (b / h if k > N // 2 else 0) for k in range(N + 1)]
        assert abs(sum((neutral[k] * D(k - 1) / D(2 * k) for k in range(2, N + 1)), D(0)) - 1) < TOL
        B = sum((D(mu[k]) * (L - D(k).ln()) / k for k in range(1, N + 1)), D(0))
        rn = [D(0)] + [residual(neutral, m) for m in range(1, limit + 1)]
        ro = [D(0)] + [residual(old, m) for m in range(1, limit + 1)]
        e = [D(0)] + [sum((v[k] * D(m % k) / D(k) for k in range(2, N + 1)), D(0))
                         for m in range(1, limit + 1)]
        for m in range(1, 2 * N + 1):
            U = sum((D(mu[k]) * (L - D(k).ln()) * (m // k)
                     for k in range(N + 1, m + 1)), D(0))
            error = abs(rn[m] - ((m * B - psi[m] + U) / L - e[m]))
            max_identity_error = max(max_identity_error, error)
            assert error < TOL
        for m in range(1, N // 4 + 1):
            error = abs(L * (rn[2 * m] - 2 * rn[m]) + psi[2 * m] - 2 * psi[m])
            max_identity_error = max(max_identity_error, error)
            assert error < TOL
        V = variance(neutral)
        assert 0 <= V <= D(16007) * N / (3 * L * L)
        tail_bound = V * (1 / D(T + 1) + D(N * N) / D((T + 1) * (T + 2)))
        assert energy(rn, T + 1, limit) <= tail_bound
        assert energy(e, 1, limit) <= D(8192) * b * b / (9 * N)
        filtered = sum(((psi[2 * m] - 2 * psi[m]) ** 2 / D(m * (m + 1))
                        for m in range(1, N // 4 + 1)), D(0)) / (16 * L * L)
        assert filtered <= energy(rn, 1, N // 2)
        rows.append({
            'N': N, 'T': T, 'stage': 'development' if K <= 4 else 'held_out',
            'old_core': str(energy(ro, 1, T)),
            'neutral_core': str(energy(rn, 1, T)),
            'neutral_head': str(energy(rn, 1, N // 2)),
            'filtered_lower_bound': str(filtered),
            'neutral_partial_tail': str(energy(rn, T + 1, limit)),
            'rigorous_formula_tail_bound_decimal': str(tail_bound),
            'mean_mass': str(b),
        })
    print(json.dumps({'python': platform.python_version(), 'precision': 80,
                      'exact_rational_cases': exact_cases,
                      'max_identity_error': str(max_identity_error), 'rows': rows}, indent=2))


if __name__ == '__main__':
    main()
```
